For You, Aryan

Adding a real project

  1. 01 Drop the project photo into images/projects/ — for example project-01.jpg. Use the same filename that's already in the card and it appears automatically.
  2. 02 In projects.html, edit the card's location, title, description and the three project-meta values.
  3. 03 Set data-cat to the right tags, e.g. data-cat="residential ongoing". The filter buttons use these.
  4. 04 Update the coloured status pill — swap the class between completed, ongoing and upcoming.
  5. 05 Need more projects? Copy any whole <a class="project-card"> block and paste it. Everything else adapts.
